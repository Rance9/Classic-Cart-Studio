# CCS Nucleus chooser

Adds the chooser to CCS Nucleus: a screen at start (and from the menu entry **CCS Nucleus**, or when you leave CCS HOME) to choose
Original Menu, CCS HOME or one of your own system images. Needs CCS Nucleus. Removing it keeps CCS Nucleus, its settings and your system
images; the console then starts the choice set in CCS Nucleus directly.

Installing this package writes files to the console's data storage (Hakchi's mod folder and Classic Cart Studio's own folder). It does
not write a kernel, a bootloader or the console's own system. Choosing one of your own system images restarts the console into it for
that start only.
