# CCS Mod for Hakchi

Classic Cart Studio's CCS HOME beside your console's existing setup: a **CCS HOME** entry in the console's own menu opens it, and
leaving it brings you back to that menu. The console starts exactly as before unless you turn on the optional start in Classic Cart
Studio.

On a console that already runs Hakchi, installing this package writes files to the console's data storage (Hakchi's mod folder, its game
folder and Classic Cart Studio's own folder). It does not write a kernel, a bootloader or the console's own system.
