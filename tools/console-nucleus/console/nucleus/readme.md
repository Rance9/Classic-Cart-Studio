# CCS Nucleus

Classic Cart Studio's start chooser for a console that runs Hakchi. Your console's own menu stays a normal choice beside CCS HOME and
any system image you add; a menu entry **CCS Nucleus** opens the chooser from your console's menu.

Installing this package writes files to the console's data storage (Hakchi's mod folder, its game folder and Classic Cart Studio's own
folder). It does not write a kernel, a bootloader or the console's own system. Choosing one of your own system images restarts the
console into it for that start only; the next start comes back to the chooser.
