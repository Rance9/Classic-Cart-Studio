# CCS Nucleus

What your console opens when you switch it on, for a console that runs Hakchi: your console's own menu (Original Menu) or CCS HOME,
started directly. Add the CCS Nucleus chooser package for a screen to choose at start, including your own system images.

Installing this package writes files to the console's data storage (Hakchi's mod folder and Classic Cart Studio's own folder). It does
not write a kernel, a bootloader or the console's own system.
